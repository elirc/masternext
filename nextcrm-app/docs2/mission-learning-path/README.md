# Mission Learning Path

This suite is a training campaign. Do not read it like a manual. For each mission, open the exact file ranges, copy the checkpoint questions into notes, answer them, then self-grade immediately.

Recommended pacing:

- Tier 1: one or two missions per study block.
- Tier 2: one mission per block, with a code trace written in your own words.
- Tier 3: one mission per longer session, preferably paired with a tiny experiment or test.

How this differs from normal documentation:

- Every mission asks you to find code, annotate real behavior, answer questions, and connect to the next skill.
- The app-specific analogy is CRM work: contacts, accounts, reports, invoices, enrichment, and the cockpit dashboard.
- A strong self-grade cites files and line ranges, names the boundary, and explains the failure mode.
