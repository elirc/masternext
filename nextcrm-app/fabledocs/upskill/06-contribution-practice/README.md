Every ticket carries an **Interview story potential** line — what STAR story finishing it produces ([08-interview-prep/06](../08-interview-prep/06-behavioral-star-stories.md)).

Contribution realism rule (applies to all): a change is mergeable only if it is *useful*, has *small blast radius*, *follows an existing pattern*, is *tested*, and wouldn't be rejected by a maintainer for scope creep or a broken contract. Each ticket answers these.
